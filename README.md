# WebMed — справочник для студентов-медиков

Учебный сайт: пошаговые описания операций, хирургические инструменты, болезни, анатомия и препараты.
Все разделы связаны ссылками: из операции можно перейти к инструментам, болезни и анатомии, а у инструмента видно, в каких операциях он используется.

> Материалы носят образовательный характер и не заменяют учебники и клинические рекомендации.

## Запуск на компьютере

Нужен [Node.js](https://nodejs.org) 20+.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет терминал (обычно http://localhost:5173).

## Публикация на GitHub Pages (бесплатно)

1. Создайте репозиторий на GitHub и загрузите в него проект (ветка `main`).
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. После каждого `git push` сайт пересобирается сам. Адрес: `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Как добавлять контент

Весь контент лежит в папке `src/data/`:

| Файл | Раздел |
|---|---|
| `operations.js` | Операции (шаги, инструменты, показания, осложнения) |
| `instruments.js` | Инструменты |
| `diseases.js` | Болезни |
| `anatomy.js` | Анатомия |
| `drugs.js` | Препараты |

- Скопируйте существующую запись и поменяйте поля. `id` — уникальный, латиницей, используется в адресе страницы.
- Связи задаются списками `id`: например у операции `instruments: ['scalpel', 'clamp-kocher']`, `diseases: ['acute-appendicitis']`. Обратные ссылки строятся автоматически.
- **Картинки**: положите файл в `public/images/` и укажите у записи `image: 'images/файл.jpg'`. У шага операции — `image` и `caption`. Без `image` у инструментов показывается встроенная схема.
- В режиме `npm run dev` в консоли браузера появятся предупреждения, если ссылка указывает на несуществующий `id`.

Используйте только изображения, на которые у вас есть права (свои фото, CC-лицензии, например Wikimedia Commons с указанием автора).

## Источники и статус проверки

- Статьи написаны по учебникам из папки `Литература/` (сама папка в репозиторий не загружается — см. `.gitignore`). Список книг — в `src/data/sources.js`.
- У записи укажите `sources: [{ book: 'nikolaev', pages: '542–545' }]` — на странице появится блок «Источники».
- `status: 'review'` показывает плашку «Статья на проверке». Когда преподаватель проверит статью, удалите эту строку.
